# Shotten Totten Project

This project is about the implementation of SHOTTEN TOTTEN game in C++ language.

## The purpose of our game : Shotten Totten<br>

<b>The goal of our project is to fulfill the following points :</b><br>
***
* Play at least one variant of Shotten Totten game
* Allow user to choose one variant to play (Variant : Base, Tactic, Expert)
* Allow user to play against another user or AI
* Develop a maintainable and extensible game
* Add new AI variant
* Configure the game
* Play the game
* Make some claim with players
* Determine the winner of the game
***

## Presentation of Shotten Totten game

Shotten Totten is a society game, and to better understand this game you have to know how works.<br>
For this purpose, we will present you the principles of this game.

***
* The Shotten Totten game oppose two players. i.e : Human vs Human, Human vs AI or AI vs AI
* The configuration of the game bord is the following :
    * Two stacks, one for <b>Clan Card</b> and another one for <b>Tactic Card</b>
    * One <b>Deffausse</b> for card which are not used
    * Nine <b>Bornes</b> each of them is composed of two <b>Player Side</b>
* There are 54 <b>Clan Card</b> each card has a number and a color : 
    * The card number is between 1 and 9
    * For each card number there are 6 different colors : 
        * RED
        * YELLOW
        * GREEN
        * PURPLE
        * BROWN
        * BLUE
***
